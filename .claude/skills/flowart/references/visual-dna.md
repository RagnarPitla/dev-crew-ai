# Flowart Visual DNA

The locked style spec for Ragnar's flow diagrams. Every prompt generated by this skill must hit every rule here.

## Palette (Locked)

| Role | Hex | Where it appears |
|---|---|---|
| Background | `#FAF7F2` | Canvas, panel fill |
| Accent | `#B8845C` | All labels, arrows, borders, ticks, dividers, brackets |
| Body text | dark gray (~`#2D2A26`) | Captions, table cells, subtitles |
| Muted | medium gray (~`#9E988F`) | Dashed "horizon" card borders + muted row |
| Signature | `#2563EB` (deep royal blue) | Only the "by Ragnar Pitla" block |

**Forbidden:** orange, red, green, purple, any gradient, any neon, any textured fill.

## Typography

- **Monospace everywhere.** No exceptions except the signature (still monospace, just colored).
- Headline: bold monospace, large (~48pt equivalent).
- Subtitle: regular monospace, two lines, dark gray.
- Card titles: bold monospace, medium.
- Card captions: regular monospace, dark gray, one line.
- Stage badges: small tan monospace uppercase (e.g., `STAGE 1`, `LAYER 0`).
- Axis labels: small tan monospace lowercase (e.g., `today`, `bridge`, `horizon`).
- Table header: tan monospace uppercase.
- Table body: dark gray monospace.
- Bookend callouts: tan monospace, sentence case, short.
- Tagline: tan monospace uppercase.
- Signature: bold monospace, royal blue, ~18pt, subtle underline.

## Canvas

- Single large soft-rounded off-white panel with a thin tan border.
- Generous whitespace. No edge-hugging.
- Soft drop shadows on cards only. Panel itself is flat.

## Card Anatomy

Each card is a soft-rounded rectangle with:
1. **Badge** at top (e.g., `STAGE 1`, `LAYER 0`, `PILLAR 1`)
2. **Title** in bold monospace (1 word if possible, 2 max)
3. **Mini-visual** (icons + thin tan arrows) that visually encodes the concept of the card
4. **Caption** below the mini-visual, one line, dark gray monospace

Cards sit on a horizontal tan arrow with tick marks aligned to each card.

**Muted card treatment** (optional): dashed tan border instead of solid, card contents rendered slightly grayer, signals "horizon/future" or "commodity/deprecated".

## Mini-Visual Vocabulary

Keep icons simple, outlined, monospace-compatible. Build from these primitives:

- **Person:** outlined figure or labeled circle
- **Agent/node:** small filled dot or outlined rounded rectangle
- **Parent/orchestrator:** rounded rectangle with small tan crown icon
- **Arrow types:** solid = flow, dashed = optional/retry, curved loop = feedback
- **Document:** rectangle with three horizontal lines + optional checkmark corner
- **Folder:** folder icon
- **Envelope:** envelope outline (used for "objective", "message", "contract")
- **Gate:** two vertical bars with a checkmark or X passing through
- **Timer/clock:** small circle with clock hands (used for autonomous/scheduled)
- **Chair with strikethrough:** user absent (Stage 4 Headless)
- **Autonomous pipeline:** 3 boxes in a row with arrows, fading left to right
- **Stack/tier:** 2-3 stacked rectangles labeled (used for memory: context / files / db)
- **Mesh/star network:** dots with full-mesh arrows (used for "team self-composes")

## Axis

A single thin tan arrow underneath all cards, running left to right, with one tick mark per card. Labels sit below the arrow, one per card position. Optional: a midpoint tag on the arrow itself (like `Agentic OS` in the Task to Objective map) that names the transition zone.

## Table

Compact, sits below the card spine. Thin tan dividers, rounded outer corners.
- **Header row:** tan monospace uppercase. 3-4 columns.
- **Data rows:** dark gray monospace, one row per card (same left-to-right order as the spine).
- **Muted row:** if a card is muted on the spine, mute its row to match.
- **Column picks:**
  - Progression: `STAGE | YOU OWN | AI OWNS | STUCK SIGNAL`
  - Anatomy: `LAYER | WHAT IT DOES | STUCK SIGNAL (MISSING IT)`
  - Journey: `STEP | WHO ACTS | OUTPUT | FAILURE MODE`
  - Framework: `PILLAR | DEFINITION | EXAMPLE`

## Bookends

Two small callouts **outside the table**, in the upper-left and upper-right of the main canvas area:
- LEFT BOOKEND points to leftmost card with a thin tan arrow. Text: `TODAY: {one-line}`.
- RIGHT BOOKEND points to the destination card with a thin tan arrow. Text: `TOMORROW: {one-line}`.

Keep callouts to 8-14 words. These carry the persuasion.

## Bottom-Left Tagline

Uppercase monospace tan, one line, spans the bottom-left of the canvas. Structure: `CLAIM, CONTRAST, PUNCHLINE`. No em dashes. Use commas.

## Signature (Mandatory)

```
BOTTOM-RIGHT of canvas: bold monospace signature "by Ragnar Pitla" in deep
royal blue (#2563EB), ~18pt (slightly larger than a footnote), very visible,
with a subtle blue underline accent. Positioned in the bottom-right corner
of the canvas panel with clean spacing from the edge.
```

This block is pasted verbatim into every generated prompt. Never paraphrase.

## Forbidden

- Em dashes anywhere in text output
- Gradients, 3D, neon, sketch/hand-drawn
- Orange (would fight the tan)
- Serif or decorative fonts
- Missing or recolored signature
- Cards outside 3-5 count
- Nested sub-cards or diagonal layouts
