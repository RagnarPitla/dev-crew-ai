# Flowart Worked Examples

Two reference prompts that this skill should mirror exactly in structure and voice. Use these to calibrate tone, card count, bookend style, and tagline cadence.

---

## Example 1: "From Task to Objective" (Progression)

**Shape:** 4 cards, Stage 4 muted (horizon treatment), axis reads as a timeline, bracket optional.
**Top-left label:** `THE MAP`
**Table columns:** `STAGE | YOU OWN | AI OWNS | STUCK SIGNAL`

- Axis labels (`today / bridge / destination / horizon`) tell the time story under the spine.
- Tagline uses commas, not em dashes.

## Example 2: "Agent = Model + Harness" (Anatomy)

**Top-left label:** `THE ANATOMY`

- Right bookend arrow points to the bracket, not to a single card. This is deliberate.
- Axis reads as a transformation (`raw to coordinated to persistent to trustworthy`), not a timeline.
- Same tagline cadence (`CLAIM, CONTRAST`) as Example 1.

## Pattern Recipes (Quick Reference)

| User concept | Label | Cards | Muted? | Bracket? | Axis |
|---|---|---|---|---|---|
| Progression over time | `THE MAP` | 3-4, final muted if "horizon" | Yes, last card | Optional | timeline (today/bridge/destination/horizon) |
| Anatomy of one thing | `THE ANATOMY` | 3-5, commodity muted if relevant | Yes, commodity card | Yes, over meaningful subset | transformation (adjective ladder) |
| Stack/architecture | `THE STACK` | 3-5 layers bottom-up or left-right | No | Optional | abstraction level |
| User journey | `THE JOURNEY` | 4-5 steps | No | No | process stages |
| Framework with pillars | `THE FRAMEWORK` | 3-5 pillars | No | No | comparison (just position) |
