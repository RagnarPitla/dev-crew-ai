# /grill-me

Use this skill before planning or implementation when the request is ambiguous, risky, broad, or likely to create hidden assumptions.

## Output

Write a concise response with:

1. Clean request restatement.
2. Missing acceptance criteria.
3. Hidden assumptions.
4. Safety and privacy risks.
5. Recommended implementation boundary.
6. Questions only if the task cannot safely proceed without the answer.

Do not write code.
