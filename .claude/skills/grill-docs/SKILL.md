# /grill-docs

Use this skill when a document, issue, plan, or spec needs to be checked before implementation.

## Output

Return:

1. Clarity verdict: PASS or NEEDS WORK.
2. Ambiguous terms.
3. Missing examples.
4. Missing acceptance criteria.
5. Missing safety or privacy boundaries.
6. Suggested concise edits.

Do not implement the feature.
