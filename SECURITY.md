# Security Policy

## Supported versions

Dev Crew AI is early-stage. Security fixes are applied to the latest mainline code in this repository.

## Reporting a vulnerability

Please do not open public issues for suspected vulnerabilities.

Instead:

1. Email: ragnar@devcrew.ai
2. Include a clear description, impact, and reproduction steps.
3. If possible, include suggested mitigation.

You can expect:

- Initial acknowledgment within 5 business days
- Triage and severity assessment after reproduction
- Coordinated disclosure guidance once a fix is available

## Scope guidance

Useful reports include:

- Remote code execution risks
- Command injection
- Path traversal
- Secrets exposure
- Privilege escalation
- Unsafe default settings that impact users

Out of scope:

- Social engineering attempts
- Vulnerabilities only affecting unsupported dependencies without a practical exploit path in this project
