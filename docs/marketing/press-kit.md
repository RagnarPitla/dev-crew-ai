## Short description

Dev Crew AI is a local-first Parallel Development Studio for AI coding agents. It helps developers run multiple AI coding sessions in visible, isolated terminal lanes across GitHub repos, local Git repos, and plain folders.

## Long description

Dev Crew AI is an open-source desktop application for developers who want to coordinate multiple AI coding agents without losing control of their codebase. It supports a local-first workflow where users can start from a GitHub repository, a local Git repository, or a plain folder. When Git is available, agent work can be isolated into lanes with branches and worktrees. When Git is not available, Dev Crew AI can guide users toward initializing local Git so changes are trackable and reversible before AI agents edit files.

The product is designed as an orchestration layer around existing AI tools such as Claude Code, GitHub Copilot, Codex, OpenCode, Aider, Ollama, Hermes, and custom command-line agents.
