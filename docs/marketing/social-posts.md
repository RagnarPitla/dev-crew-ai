## LinkedIn — building in public

I’m building Dev Crew AI with RBuild.ai.

Dev Crew AI is an open-source, local-first Parallel Development Studio for AI coding agents.

The idea is simple:

Instead of running one AI coding session in one terminal, Dev Crew AI gives you a visual workspace where each task can run in its own lane:

- one pane for a feature;
- one pane for a bugfix;
- one pane for docs;
- one pane for review;
- one branch/worktree when Git is available;
- one visible message bus for coordination.

It is designed to work with GitHub repos, local Git repos, and even plain folders that are not on GitHub yet.

The long-term goal: make local AI development safer, faster, and more visible — especially for developers using tools like Claude Code, GitHub Copilot, Codex, OpenCode, Aider, Ollama, Hermes, or custom commands.

Current repo includes the Electron app scaffold, local-first project model, Git/GitHub foundations, provider adapter docs, safety docs, product docs, and an interactive terminal workspace mockup.

Building in public. More screenshots and demos coming soon.

GitHub: https://github.com/RagnarPitla/dev-crew-ai

## X / Twitter — thread

1/ I’m building Dev Crew AI with RBuild.ai.

It’s an open-source, local-first desktop app for running multiple AI coding agents safely in parallel.

2/ Most AI coding workflows are still one terminal, one branch, one agent session at a time.

That is too slow when you want to work on features, bugs, docs, reviews, and experiments in parallel.

3/ Dev Crew AI turns work into visible lanes:

- one lane per task;
- one provider per lane;
- one terminal pane per agent;
- one branch/worktree when Git is available;
- one message bus for coordination.

4/ It is local-first.

You can start with:

- a GitHub repo;
- a local Git repo;
- a plain folder.

If there is no Git yet, Dev Crew AI can initialize local Git before agent edits begin.

5/ Bring your own agent:

Claude Code, GitHub Copilot, Codex, OpenCode, Aider, Ollama, Hermes, or any custom command.

Dev Crew AI is the orchestration layer, not a replacement for the agents.

6/ Current repo has the Electron app scaffold, local-first project model, Git/GitHub foundations, provider adapter docs, safety docs, product docs, and an interactive terminal workspace mockup.

GitHub: https://github.com/RagnarPitla/dev-crew-ai
