# Flowart Skill

Flowart is Ragnar's signature Lovart prompt generator for clean framework and flow diagrams.

## Where it lives

| Surface | File |
|---------|------|
| Claude skill | `.claude/skills/flowart/SKILL.md` |
| Claude skill references | `.claude/skills/flowart/references/` |
| GitHub Copilot prompt | `.github/prompts/flowart.prompt.md` |

## When to use it

Use Flowart when you need:

- a one-visual explainer;
- a flow map;
- a framework diagram;
- a concept anatomy;
- a Lovart prompt in Ragnar's signature diagram style.

## Style

Flowart locks the visual language:

- cream canvas;
- tan monospace cards;
- horizontal card spine;
- bottom data table;
- bookend callouts;
- royal-blue `by Ragnar Pitla` signature.

## Demo prompt

```text
/flowart harness engineering anatomy
```

For GitHub Copilot users, open `.github/prompts/flowart.prompt.md` and ask it to generate a Lovart prompt for the concept.
