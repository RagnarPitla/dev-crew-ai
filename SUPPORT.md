# Support

## Get help

- Usage questions and setup help: open a GitHub Discussion
- Bugs: open a GitHub Issue with repro steps and logs
- Security concerns: follow [/SECURITY.md](/SECURITY.md)

## Before opening an issue

- Confirm you are using Node.js 20+
- Run:

```bash
npm install
npm run test
npm run build
```

- Include environment details (OS, Node version, provider CLI used)
- Include relevant terminal output

## Response expectations

This is an early open-source project. Maintainer response times can vary, but clear reproduction details usually get triaged faster.
